Классы, наследование и модули

ООП и организация кода

Классы

ES6 ввёл ключевое слово class, которое предоставляет более элегантный способ создания объектов и реализации наследования по сравнению с ручной работой с прототипами. Синтаксис классов в JavaScript ближе к традиционным объектно-ориентированным языкам, что упрощает переход разработчикам из других экосистем.

class User {
    constructor(name, age) {
        this.name = name;
        this.age = age;
    }

    greet() {
        return `Привет, я ${this.name}!`;
    }
}

const ivan = new User("Иван", 30);
console.log(ivan.greet()); // "Привет, я Иван!"

Что внутри класса

  • constructor() — вызывается автоматически при создании объекта через new.
  • Методы — определяются внутри тела класса без ключевого слова function.
  • Статические методы — объявляются с ключевым словом static, вызываются на самом классе, а не на экземпляре.
  • Геттеры и сеттеры — через get и set.

Наследование через extends

Ключевое слово extends создаёт класс, который является дочерним по отношению к другому классу. Конструктор родительского класса вызывается через super().

class Animal {
    constructor(name) {
        this.name = name;
    }

    speak() {
        return `${this.name} издаёт звук`;
    }
}

class Dog extends Animal {
    constructor(name, breed) {
        super(name);           // вызов конструктора родителя
        this.breed = breed;
    }

    speak() {
        return `${this.name} лает`;
    }
}

const rex = new Dog("Рекс", "овчарка");
console.log(rex.speak()); // "Рекс лает"
console.log(rex.breed);   // "овчарка"

Если дочерний класс определяет собственный constructor, он обязан вызвать super() до обращения к this.

Приватные поля

ES2022 добавил приватные поля через символ #. Такие свойства и методы доступны только внутри класса.

class Counter {
    #count = 0;

    increment() {
        this.#count++;
    }

    get value() {
        return this.#count;
    }
}

const c = new Counter();
c.increment();
console.log(c.value);   // 1
console.log(c.#count);  // SyntaxError

Модули: import и export

ES6 добавил в JavaScript встроенную модульную систему. Любой файл, содержащий инструкцию import или export на верхнем уровне, считается модулем.

Именованный экспорт

// utils.js
export const PI = 3.14;
export function double(x) {
    return x * 2;
}
// main.js
import { PI, double } from "./utils.js";
console.log(PI);       // 3.14
console.log(double(5)); // 10

Экспорт по умолчанию

// user.js
export default class User {
    constructor(name) {
        this.name = name;
    }
}
// main.js
import User from "./user.js";
const user = new User("Иван");

Переименование при импорте

import { double as d } from "./utils.js";
console.log(d(5)); // 10

Импорт всего модуля

import * as utils from "./utils.js";
console.log(utils.PI);
console.log(utils.double(5));

Подключение модулей в браузере

Чтобы использовать модули в HTML, подключите скрипт с атрибутом type="module":

<script type="module" src="js/main.js"></script>

Важно: модули работают только при загрузке через сервер (http:// или https://), а не через file://. В VS Code используйте расширение Live Server.

Сравнение классов и функций-конструкторов

Класс vs функция-конструктор
Характеристика Функция-конструктор Класс
Синтаксис Многословный Компактный
Поднятие (hoisting) Да Нет
Вызов без new Работает TypeError
Приватные поля Через замыкания Через #
Наследование Через prototype Через extends

Лучшие практики

  • Используйте классы, когда у вас есть несколько объектов с одинаковой структурой и поведением.
  • Не злоупотребляйте наследованием — предпочитайте композицию, если цепочка классов становится глубокой.
  • Приватные поля # предпочтительнее «договорённости» с подчёркиванием (_field).
  • Разделяйте код на модули: один модуль — одна ответственность.
  • Экспорт по умолчанию удобен для главного класса/функции модуля, именованный — для утилит.
