Деструктуризация, spread и rest

Элегантная работа с массивами и объектами

Деструктуризация объектов

Деструктурирующее присваивание позволяет извлекать свойства из объектов и присваивать их переменным в одной лаконичной конструкции. Это значительно сокращает количество строк кода.

До ES6:

const user = { name: "Иван", age: 30 };
const name = user.name;
const age = user.age;
console.log(name, age); // "Иван" 30

С деструктуризацией:

const user = { name: "Иван", age: 30 };
const { name, age } = user;
console.log(name, age); // "Иван" 30

Переименование переменных

Если имя свойства не подходит под имя переменной, можно его переименовать:

const user = { name: "Иван", age: 30 };
const { name: userName, age: userAge } = user;
console.log(userName); // "Иван"

Значения по умолчанию

const user = { name: "Иван" };
const { name, age = 18 } = user;
console.log(age); // 18

Вложенная деструктуризация

const user = {
    name: "Иван",
    address: {
        city: "Москва",
        zip: "101000"
    }
};
const { address: { city, zip } } = user;
console.log(city); // "Москва"

Деструктуризация массивов

Работает аналогично, но с элементами массива. Порядок важен — переменные получают значения по позиции.

const colors = ["красный", "зелёный", "синий"];
const [first, second, third] = colors;
console.log(first);  // "красный"
console.log(second); // "зелёный"

Пропуск элементов

const colors = ["красный", "зелёный", "синий"];
const [first, , third] = colors;
console.log(third); // "синий"

Rest-элемент в массиве

const numbers = [1, 2, 3, 4, 5];
const [first, ...rest] = numbers;
console.log(first); // 1
console.log(rest);  // [2, 3, 4, 5]

Spread-оператор

Spread-оператор ... «разворачивает» массив или объект на отдельные элементы. Чаще всего используется для копирования и объединения.

Копирование массива

const original = [1, 2, 3];
const copy = [...original];
console.log(copy); // [1, 2, 3]

Объединение массивов

const a = [1, 2];
const b = [3, 4];
const combined = [...a, ...b];
console.log(combined); // [1, 2, 3, 4]

Копирование и объединение объектов

const user = { name: "Иван", age: 30 };
const updated = { ...user, age: 31 };
console.log(updated); // { name: "Иван", age: 31 }

Передача массива в функцию

const numbers = [3, 7, 2, 9];
console.log(Math.max(...numbers)); // 9

Rest-параметры

Rest-параметры используют тот же синтаксис ..., но выполняют противоположную задачу: «сворачивают» произвольное количество аргументов в массив.

function sum(...numbers) {
    return numbers.reduce((acc, n) => acc + n, 0);
}

console.log(sum(1, 2, 3));       // 6
console.log(sum(1, 2, 3, 4, 5)); // 15

Rest-параметр всегда должен идти последним в списке параметров:

function log(level, ...messages) {
    console.log(`[${level}]`, ...messages);
}

log("INFO", "Сервер запущен", "порт 3000");

Spread vs rest: в чём разница

Сравнение двух применений оператора ...
Синтаксис Где используется Что делает
Spread При вызове функции, в литералах массивов и объектов Разворачивает итерируемое в отдельные элементы
Rest В списке параметров функции, в деструктуризации Собирает оставшиеся элементы в массив

Лучшие практики

  • Используйте деструктуризацию в параметрах функций — это делает сигнатуру явной:
function greet({ name, age }) {
    return `Привет, ${name}! Тебе ${age}.`;
}

greet({ name: "Иван", age: 30 });
  • Копируйте массивы и объекты через spread вместо slice() или Object.assign() — короче и безопаснее.
  • Не мутируйте исходные данные: const updated = { ...user, age: 31 } предпочтительнее, чем user.age = 31.
  • Rest-параметр ставьте последним — иначе будет синтаксическая ошибка.
