Коллекции и методы массивов

Map, Set и функциональные паттерны

Map

Map — это коллекция пар «ключ-значение», где ключами могут быть любые типы данных, включая объекты. В отличие от обычных объектов, Map сохраняет порядок вставки, поддерживает итерацию и имеет свойство size.

const map = new Map();
map.set("name", "Иван");
map.set(42, "ответ");
map.set(true, "истина");

console.log(map.get("name")); // "Иван"
console.log(map.size);        // 3
console.log(map.has(42));     // true

Перебор Map

for (const [key, value] of map) {
    console.log(key, value);
}

map.forEach((value, key) => {
    console.log(key, "=>", value);
});

Когда использовать Map вместо объекта

  • Ключи не строки (числа, объекты, булевы значения).
  • Важен порядок вставки.
  • Нужно часто добавлять и удалять элементы.
  • Нужно знать точное количество элементов.

Set

Set — это коллекция уникальных значений. Set автоматически удаляет дубликаты.

const set = new Set([1, 2, 2, 3, 3, 3]);
console.log(set);      // Set(3) {1, 2, 3}
console.log(set.size); // 3

set.add(4);
set.delete(1);
console.log(set.has(2)); // true

Удаление дубликатов из массива

const numbers = [1, 2, 2, 3, 3, 4];
const unique = [...new Set(numbers)];
console.log(unique); // [1, 2, 3, 4]

WeakMap и WeakSet

Это «слабые» версии Map и Set, которые не предотвращают сборку мусора для своих ключей (в WeakMap) или значений (в WeakSet). Они полезны для кэширования, хранения метаданных и предотвращения утечек памяти.

const cache = new WeakMap();

function process(obj) {
    if (cache.has(obj)) {
        return cache.get(obj);
    }
    const result = obj.value * 2;
    cache.set(obj, result);
    return result;
}

Важно: в WeakMap и WeakSet ключи/значения — только объекты, и они недоступны для перебора (нет size и итераторов).

Методы массивов: map, filter, reduce

Трио map, filter и reduce стало стандартным инструментом для трансформации, фильтрации и агрегации данных.

map — преобразование

const nums = [1, 2, 3];
const doubled = nums.map(n => n * 2);
console.log(doubled); // [2, 4, 6]

filter — фильтрация

const nums = [1, 2, 3, 4, 5];
const even = nums.filter(n => n % 2 === 0);
console.log(even); // [2, 4]

reduce — свёртка

const nums = [1, 2, 3, 4];
const sum = nums.reduce((acc, n) => acc + n, 0);
console.log(sum); // 10

Цепочки методов

const users = [
    { name: "Иван", age: 30 },
    { name: "Мария", age: 17 },
    { name: "Пётр", age: 25 }
];

const adultNames = users
    .filter(u => u.age >= 18)
    .map(u => u.name);

console.log(adultNames); // ["Иван", "Пётр"]

Иммутабельные альтернативы

Современный JavaScript предпочитает иммутабельные методы — они не меняют исходный массив, а возвращают новый.

const nums = [3, 1, 2];

// Старый способ (мутирует)
nums.sort();      // [1, 2, 3], но nums изменён

// Новый способ (иммутабельный)
const sorted = nums.toSorted(); // nums не изменён

Лучшие практики

  • Используйте Map, когда ключи — не строки или важно сохранить порядок вставки.
  • Set — идеальный инструмент для удаления дубликатов.
  • WeakMap и WeakSet — для кэша и метаданных, привязанных к объектам.
  • Предпочитайте map/filter/reduce циклу for — код декларативнее.
  • Используйте иммутабельные методы (toSorted, toReversed, with) вместо мутирующих.
