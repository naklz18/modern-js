Возможности ES2020–ES2025

Что нового появилось в JavaScript за последние годы

ES2020

Опциональная цепочка (?.) позволяет безопасно обращаться к вложенным свойствам объектов, не беспокоясь о том, что промежуточное значение может быть null или undefined.

const user = { address: { city: "Москва" } };
console.log(user?.address?.city);   // "Москва"
console.log(user?.phone?.number);   // undefined (без ошибки)

Оператор нулевого слияния (??) предоставляет значение по умолчанию только для null и undefined, в отличие от ||, который срабатывает на любое «ложное» значение.

const count = 0;
console.log(count || 10); // 10 — потому что 0 это falsy
console.log(count ?? 10); // 0 — потому что 0 это не null/undefined

BigInt — новый примитивный тип для работы с целыми числами произвольной точности.

const big = 9007199254740991n;
console.log(big + 1n); // 9007199254740992n

Promise.allSettled() — ждёт завершения всех промисов и возвращает массив результатов, независимо от того, были ли они успешными или отклонёнными.

ES2021

String.prototype.replaceAll() — заменить все вхождения подстроки, а не только первое.

"a-b-c".replaceAll("-", "_"); // "a_b_c"

Promise.any() — возвращает результат первого успешно завершившегося промиса.

Логические операторы присваивания (??=, ||=, &&=) — совмещают проверку и присваивание.

let user = null;
user ??= "Гость"; // user = "Гость"

Числовые разделители — улучшают читаемость больших чисел.

const million = 1_000_000;

ES2022

Top-level await — позволяет использовать await на верхнем уровне модуля, вне асинхронной функции.

const response = await fetch("/api/data");
const data = await response.json();

Приватные поля классов (#field) — делают свойства и методы действительно приватными.

class Counter {
    #count = 0;
    increment() { this.#count++; }
}

Статические блоки — позволяют выполнять инициализацию статических свойств класса.

class Config {
    static data;
    static {
        Config.data = loadConfig();
    }
}

Метод .at() — получить элементы по относительному индексу.

[1, 2, 3].at(-1); // 3

ES2023

Иммутабельные методы массивов: toSorted(), toReversed(), with() — не изменяют исходный массив, а возвращают новый.

const nums = [3, 1, 2];
const sorted = nums.toSorted();
console.log(nums);   // [3, 1, 2] — не изменён
console.log(sorted); // [1, 2, 3]

findLast() и findLastIndex() — ищут элементы с конца массива.

[1, 2, 3, 4].findLast(n => n % 2 === 0); // 4

ES2024

Object.groupBy() и Map.groupBy() — группировка элементов коллекции по ключу.

const items = [
    { type: "fruit", name: "яблоко" },
    { type: "veg", name: "морковь" },
    { type: "fruit", name: "банан" }
];

const grouped = Object.groupBy(items, item => item.type);

Promise.withResolvers() — упрощает создание промисов с внешним управлением.

ArrayBuffer получил возможности изменения размера и передачи между воркерами.

ES2025

Новый глобальный объект Iterator с методами для работы с итераторами.

Методы Set.prototype для операций над множествами: объединение, пересечение, разность.

Импорт JSON-модулей — теперь можно импортировать JSON напрямую:

import data from "./data.json" with { type: "json" };

RegExp.escape() — безопасное экранирование строк для регулярных выражений.

Promise.try() — обработка синхронных и асинхронных ошибок единообразно.

Лучшие практики

  • Используйте ?. и ?? вместо громоздких проверок — код становится короче и безопаснее.
  • Применяйте иммутабельные методы (toSorted, with) — они снижают количество багов.
  • Top-level await упрощает инициализацию модулей, но не злоупотребляйте им в библиотеках — это может замедлить загрузку.
  • Перед использованием новых возможностей проверьте поддержку в целевых браузерах (Can I use).
  • Для production-сборки используйте Babel или Vite — они транспилируют новый синтаксис под старые браузеры.

Совет
