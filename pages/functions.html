Стрелочные функции и шаблонные строки

Краткий синтаксис и лексический this

Стрелочные функции

Стрелочные функции (arrow functions) предлагают более краткий синтаксис для записи функций и принципиально иначе обрабатывают контекст this. В отличие от обычных функций, стрелочные функции не создают собственный this — они заимствуют его из окружающей области видимости (лексическая привязка).

Синтаксис

Полный вариант записи:

const sum = (a, b) => {
    return a + b;
};

Если тело функции состоит из одного выражения, можно опустить фигурные скобки и ключевое слово return:

const sum = (a, b) => a + b;

Если параметр один, скобки тоже можно опустить:

const double = x => x * 2;

Если параметров нет — нужны пустые скобки:

const greet = () => "Привет!";

Возврат объекта

Если нужно вернуть объект из стрелочной функции, его следует обернуть в круглые скобки, иначе фигурные скобки будут восприняты как тело функции:

// Неправильно — вернёт undefined
const makeUser = name => { name: name };

// Правильно
const makeUser = name => ({ name: name });

Лексический this

Это ключевое отличие стрелочных функций. В обычных функциях this определяется тем, как функция была вызвана. В стрелочных — тем, где она была объявлена.

Классическая проблема с колбэками:

const timer = {
    seconds: 0,
    start() {
        setInterval(function() {
            this.seconds++; // this — не timer, а глобальный объект
            console.log(this.seconds); // NaN
        }, 1000);
    }
};

Решение через стрелочную функцию:

const timer = {
    seconds: 0,
    start() {
        setInterval(() => {
            this.seconds++; // this — это timer
            console.log(this.seconds); // 1, 2, 3...
        }, 1000);
    }
};

Правило: стрелочные функции удобны для колбэков, обработчиков событий и цепочек промисов, где традиционные функции могли привести к потере контекста. Но их нельзя использовать как методы объектов или конструкторы.

Шаблонные строки (Template Literals)

Шаблонные строки — это строковые литералы, заключённые в обратные кавычки (`), которые поддерживают интерполяцию выражений через синтаксис ${...} и позволяют создавать многострочные строки без использования специальных символов.

Интерполяция

До ES6 для конкатенации строк приходилось использовать оператор +:

const name = "Иван";
const age = 30;
const greeting = "Привет, " + name + "! Тебе " + age + " лет.";

С шаблонными строками это выглядит элегантнее:

const greeting = `Привет, ${name}! Тебе ${age} лет.`;

Внутри ${...} можно помещать любые выражения, а не только переменные:

const price = 100;
const total = `Итого: ${price * 1.2} руб.`;

Многострочные строки

Раньше для переноса строк приходилось использовать \n:

const html = "<div>\n  <p>Текст</p>\n</div>";

Теперь можно просто писать как есть:

const html = `
<div>
    <p>Текст</p>
</div>`;

Сравнение подходов

Обычные функции vs стрелочные
Характеристика Обычная функция Стрелочная функция
Краткий синтаксис Нет Да
Собственный this Да Нет (лексический)
Можно использовать как метод Да Не рекомендуется
Можно использовать как конструктор Да Нет
Объект arguments Да Нет

Лучшие практики

  • Используйте стрелочные функции для колбэков и обработчиков, где важно сохранить this.
  • Не используйте стрелочные функции как методы объектов — они не получат собственный this.
  • Шаблонные строки предпочтительнее конкатенации через + — они короче и читаемее.
  • Для сложной логики в интерполяции (например, тернарных выражений) лучше вынести её в отдельную переменную.

Совет

Если внутри ${...} становится тесно — это знак, что логику лучше вынести в отдельную переменную или функцию перед формированием строки.
