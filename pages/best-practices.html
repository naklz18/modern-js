Критерии выбора и лучшие практики

Как писать современный, читаемый и производительный JavaScript

Использование let и const вместо var

Современный JavaScript-код должен использовать let и const вместо var. Это обеспечивает блочную область видимости, которая более предсказуема и снижает количество ошибок, связанных с неожиданным доступом к переменным.

// Плохо
var count = 0;

// Хорошо
const MAX = 100;
let count = 0;

Предпочтение иммутабельности

Иммутабельные операции снижают количество побочных эффектов и делают код более предсказуемым. Вместо мутирующих методов (sort(), reverse(), splice()) следует использовать их иммутабельные аналоги (toSorted(), toReversed(), toSpliced()).

// Плохо — мутирует исходный массив
users.sort((a, b) => a.age - b.age);

// Хорошо — возвращает новый массив
const sorted = users.toSorted((a, b) => a.age - b.age);

Функциональные паттерны

Функциональный стиль программирования с использованием map, filter, reduce и других методов массивов делает код более декларативным и читаемым. Цепочки методов позволяют выражать сложные трансформации данных лаконично и понятно.

const total = orders
    .filter(order => order.status === "paid")
    .map(order => order.amount)
    .reduce((sum, amount) => sum + amount, 0);

Асинхронное программирование

Для асинхронных операций следует предпочитать async/await вместо цепочек .then(). Это делает код более линейным и легким для отладки. Избегайте использования await внутри циклов, где это возможно, — вместо этого используйте Promise.all() для параллельного выполнения.

// Плохо — последовательно
for (const id of ids) {
    const user = await getUser(id);
    results.push(user);
}

// Хорошо — параллельно
const results = await Promise.all(
    ids.map(id => getUser(id))
);

Обработка ошибок

Всегда включайте обработку ошибок в асинхронный код. try/catch вокруг await позволяет перехватывать ошибки так же, как в синхронном коде. Для промисов без async/await используйте .catch().

async function loadUser(id) {
    try {
        const user = await fetchUser(id);
        return user;
    } catch (error) {
        console.error("Не удалось загрузить пользователя:", error);
        return null;
    }
}

Производительность

Современный JavaScript предлагает несколько паттернов для оптимизации производительности:

  • Батчинг DOM-обновлений снижает количество перерисовок.
  • Web Workers позволяют вынести тяжёлые вычисления из основного потока.
  • Избегание длинных задач (более 50 мс) сохраняет отзывчивость интерфейса.
  • Сохранение формы объектов (hidden classes) помогает движку V8 оптимизировать код.

Инструменты сборки и транспиляции

Современная разработка на JavaScript редко обходится без инструментов сборки:

  • Babel — транспайлер, преобразует современный JavaScript в код, совместимый со старыми браузерами.
  • Webpack — модульный бандлер, собирает все зависимости проекта в один или несколько файлов.
  • Vite — современная альтернатива с молниеносным запуском dev-сервера и использованием esbuild/Rollup.
